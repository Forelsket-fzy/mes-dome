## 版本 A（推荐 · 约 8～10 行）

**制造执行系统 MES-dome**｜个人项目  
*2026.xx – 2026.xx*  
技术栈：Spring Boot 4.1 · Java 17 · MyBatis-Plus · MySQL · Redis/Redisson · RocketMQ · Spring Security/JWT · Vue3/Element Plus · Docker Compose

- 独立设计并实现车间执行主链路：ERP Mock 推单 → 工单状态流转 → 主动派工 → 扫码报工 → 自动完工 → 回传 ERP，覆盖管理端与工人终端双端演示
- 手写工单 7 态状态机，约束非法跃迁；报工后按计划量/完工量/是否末工序自动计算下一状态，末工序满额自动完工，避免人工改状态导致数据不一致
- 报工采用「同步校验 + 202 异步受理 + 轮询」模型：Redis `SET NX`（`X-Request-Id`）防连点，Redisson 任务锁 + MyBatis-Plus 乐观锁防并发超报，RocketMQ 消费幂等与 `request_id` 唯一键防消息重复
- 集成侧通过独立 Topic 回传 Mock ERP，落库 IntegrationLog（幂等键 + 状态机），支持失败手动重试与定时扫描重试，保证跨系统最终一致可运营
- 使用 Docker Compose 编排 MySQL/Redis/RocketMQ；完成双令牌 JWT 鉴权与基于角色的接口鉴权（计划员/工人等）
