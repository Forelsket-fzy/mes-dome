# MES-dome 面试讲稿（提纲）

## 1. 项目一句话（30s）

做了一个车间 MES 精简版：ERP Mock 推单 → 状态机驱动工单 → 主动派工 → 扫码报工（MQ 异步）→ 自动完工 → 回传 ERP，并用 IntegrationLog 做对账重试。

## 2. 为什么用三层防重复？

| 层 | 手段 | 防什么 |
|----|------|--------|
| API | Redis `SET NX` + `X-Request-Id` | 前端连点、网络重试 |
| 并发 | Redisson 锁 `taskId` + `@Version` | 同工序并发超报 |
| MQ/DB | Consumer 幂等 + `request_id` UK | 消息重复投递 |

面试说法：任何一层单独都不够，组合后接近「至少一次投递 + 业务幂等」。

## 3. 状态机怎么讲？

- 7 态：已下发 → 已派工 → 执行中 → 部分完工 → 已完工 → 已关闭 / 已取消
- 报工后用 `resolveAfterReport(plan, completed, lastOpDone)` 算下一态
- **已完工是自动算出来的**，不是工人点按钮

## 4. MQ 怎么讲？

- Topic：`mes_report_submit` 落库；`mes_erp_callback` 回传
- 消费失败 `RECONSUME_LATER`；业务对账靠 `integration_log`
- Dashboard 没有「Producer 发送流水」不代表没发出去——看 Topic/Consumer/msgId
