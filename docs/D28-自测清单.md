# D28 自测清单（主链路）

- [ ] 同一 `X-Request-Id` 连点 5 次 → `production_report` 仅 1 条
- [ ] 并发对同一 `taskId` 超报 → 接口或消费拒绝，`completed_qty` 不超过 `plan_qty`
- [ ] Consumer 处理失败返回 `RECONSUME_LATER` → Broker 重试；业务失败写 `status=2`
- [ ] 报工成功后 `integration_log` 出现 `REPORT_CALLBACK` 且最终 `status=1`
- [ ] 将日志改为失败后，管理端点「重试」或等定时任务 → 回传成功
- [ ] 末工序报满 → 工单状态自动变为「已完工」
- [ ] 含不良报工 → `quality_inspection_task` 自动生成
- [ ] 日志出现 `[AUDIT]` 派工/报工审计行

## 建议 Apifox 顺序

1. `POST /api/auth/login`（worker1）
2. `POST /api/reports` + Header `X-Request-Id`
3. `GET /api/reports/{id}` 轮询
4. `GET /api/integration/logs`
5. `POST /api/integration/logs/{id}/retry`（可选）
